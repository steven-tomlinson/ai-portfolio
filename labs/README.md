# Laboratory Artifacts

This directory contains hands-on lab exercises and artifacts from AI certification courses.

## About Labs

Labs are practical exercises that reinforce learning from certification courses. Each lab includes:
- Clear objectives
- Step-by-step procedures
- Results and observations
- Key learnings

## Lab Organization

Labs are organized by:
- Course name
- Module number
- Lab number
- Topic

## Creating a Lab Report

1. Create a new directory for your lab (e.g., `lab-01-azure-ai-intro/`)
2. Copy `LAB_TEMPLATE.md` and rename it to `README.md`
3. Complete the lab and document each step
4. Include screenshots and code samples
5. Document results and learnings

## Lab Structure

Each lab directory should include:
```
lab-name/
├── README.md          # Lab report
├── src/              # Source code
├── screenshots/      # Screenshots of results
├── data/            # Sample data if applicable
└── resources/       # Additional resources
```

## Lab Best Practices

1. **Before Starting**
   - Read objectives thoroughly
   - Ensure prerequisites are met
   - Set up environment properly

2. **During the Lab**
   - Document each step
   - Take screenshots of key results
   - Save all code and configurations
   - Note any issues or errors

3. **After Completion**
   - Review objectives to ensure all are met
   - Document learnings
   - Clean up Azure resources if needed
   - Update progress tracking

## Validation Checklist

- [ ] All objectives completed
- [ ] Code tested and working
- [ ] Screenshots captured
- [ ] Documentation complete

## Tips for Success

- Follow instructions carefully
- Don't skip steps
- Document everything as you go
- Ask for help when stuck
- Review related documentation
- Practice good security habits
- Clean up resources to avoid costs
