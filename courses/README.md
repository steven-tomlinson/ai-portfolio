# Certification Courses

This directory contains materials, projects, and artifacts from AI certification courses.

## Current Courses

### Azure AI Agent Foundry Certification
Building intelligent AI agents using Azure AI services and tools.

**Status**: In Progress  
**Location**: [azure-ai-agent-foundry/](azure-ai-agent-foundry/)

## Course Structure

Each course has its own directory with the following structure:

```
course-name/
├── index.html         # Course overview page
├── README.md          # Course documentation
├── modules/           # Course modules
├── labs/             # Course lab exercises
├── projects/         # Course projects
├── notes/            # Personal course notes
└── resources/        # Additional resources
```

## Adding a New Course

1. Create a new directory for the course
2. Set up the standard structure (modules, labs, projects, notes, resources)
3. Create a README.md with course overview
4. Optionally create an index.html for web navigation
5. Track progress in the course README

## Course Format

All courses follow a consistent format:
- **Modules**: Organized learning units
- **Labs**: Hands-on exercises
- **Projects**: Larger implementation assignments
- **Notes**: Personal learning notes
- **Resources**: Additional materials and references

## Progress Tracking

Each course README includes:
- Course overview and objectives
- Module checklist
- Lab completion status
- Project status
- Learning outcomes

## Technologies

Courses focus on:
- Azure AI Services
- Azure OpenAI Service
- Azure Bot Service
- Azure Functions
- HTML/CSS/JavaScript (preferred)
- VS Code and GitHub Copilot

## Study Best Practices

1. **Follow the sequence**: Complete modules in order
2. **Do the labs**: Hands-on practice is essential
3. **Take notes**: Document key learnings
4. **Build projects**: Apply knowledge practically
5. **Review regularly**: Reinforce learning over time

## Certification Goals

- Complete all course modules
- Finish all lab exercises
- Build required projects
- Pass assessments
- Earn certifications
