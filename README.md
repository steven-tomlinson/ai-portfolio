# AI Portfolio

Welcome to my AI portfolio! This repository contains certification lab projects, courseware, experiments, notes, and observations related to my AI research and development.

## About

This portfolio showcases my AI-focused work including:
- **Certification Projects**: Labs and projects from AI certification courses
- **Courseware**: Study materials and course artifacts
- **Laboratory Artifacts**: Hands-on lab exercises and implementations
- **Personal Experiments**: Testing AI concepts and technologies
- **Notes**: Learning notes and observations

My focus is on learning how to use AI models, libraries, tools, and technologies to create safe, secure, unique, and novel abstractions of entities and processes to enable further implementation of more complex systems.

## Tools & Technologies

I primarily work with:
- **IDE**: VS Code with GitHub Copilot
- **Platform**: Azure AI and Azure Services
- **Languages**: HTML, CSS, JavaScript (preferred over Node/React)
- **Version Control**: GitHub
